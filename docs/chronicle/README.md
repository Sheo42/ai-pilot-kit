# Chronicle: how this project is built

Maintained by the `chronicler`. The rest of `docs/` describes the product;
this folder describes the making of it, by {{OWNER}} working with AI agents.

The chronicle records the **steps** of the project at a high level, not the
decisions, technologies or IDs: those are in the ADRs, the requirements and
the code, and the chronicle links to them.

| File | Content |
|---|---|
| `journal/YYYY-MM-DD-title.md` | One short entry per session or milestone: the steps taken and why |
| `agents-history.md` | One row per change to the agents, `CLAUDE.md` or the process, with the reason and the effect |
| `lessons.md` | What to keep, change or avoid in the way of working, each with its to-do item |
