# Method: why the rules are what they are

This folder explains the **way of working**: the ideas behind the rules of
`docs/process.md`, and how to start with them. It sits between two other
records:

| Where | Answers |
|---|---|
| `docs/process.md` | The rules this project follows today |
| `docs/chronicle/` | What happened, step by step, and the lessons of each step |
| `docs/method/` (here) | Why the rules exist, and how to start a project with them |

It comes from the AI pilot kit (version in `KIT_VERSION`), written from
the record of the first project run this way. "The first project" below
means that one.
